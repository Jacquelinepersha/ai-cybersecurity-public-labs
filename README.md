# AI Cybersecurity Masterclass: Public Labs

23 hands-on labs that apply machine learning to network threat detection, using the UNSW-NB15 dataset. Built to accompany the AI Cybersecurity Masterclass from [AI60secLab](https://ai60seclab.com), and shared here as public, runnable evidence of the work, not just slides.

**Level: advanced.** You should already be comfortable with Python, pandas, and scikit-learn.

This is an independent educational project, not an accredited certification program.

## Run a lab in one click

Click any **Open in Colab** badge below, then choose **Runtime → Run all**. The first cell clones this repo, which already includes the dataset, so there is nothing to download or upload.

## Run locally

```bash
git clone https://github.com/Jacquelinepersha/ai-cybersecurity-public-labs.git
cd ai-cybersecurity-public-labs
pip install -r requirements.txt
jupyter lab notebooks/
```

The dataset loads automatically from `data/raw/` (see `data/README.md`). Labs 18–21 also download the official MITRE ATT&CK and ATLAS data at runtime, so they need an internet connection.

## Repository structure

```
ai-cybersecurity-public-labs/
├── notebooks/     # labs 00–22
├── src/           # shared data loading, preprocessing, modeling, evaluation, and security helpers
├── data/raw/      # compressed UNSW-NB15 prepared train/test partition

└── LICENSE
```

## Core technology

Python · pandas · scikit-learn · XGBoost · matplotlib · Jupyter / Google Colab · UNSW-NB15 · MITRE ATT&CK · MITRE ATLAS

## Method

Each lab follows the same structure: research question, method, results, and a short written interpretation, not just a final score. The core rule throughout: evaluate precision, recall, and F1 alongside accuracy, since accuracy alone can hide the failures that matter most in security data.
