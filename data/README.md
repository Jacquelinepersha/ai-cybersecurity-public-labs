# Data

The raw dataset is **not** included in this repository. Download it yourself and
place the prepared CSV files in `data/raw/`.

## Source

UNSW-NB15 dataset — Cyber Range Lab, UNSW Canberra:
https://research.unsw.edu.au/projects/unsw-nb15-dataset

These labs use the **prepared training and testing partition**, not the raw pcap
or full-feature CSVs.

## Expected files

```
data/raw/
├── UNSW_NB15_training-set.csv
├── UNSW_NB15_testing-set.csv
└── UNSW_NB15_features.csv   (optional — column dictionary)
```

## Citation

Moustafa, N. and Slay, J. (2015). *UNSW-NB15: a comprehensive data set for
network intrusion detection systems.* Military Communications and Information
Systems Conference (MilCIS), IEEE.

Please review and follow the dataset's own terms of use on the UNSW page above.
